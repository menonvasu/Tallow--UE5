It refuses existing asset paths, imports source OBJ and creates only /Game/Presentation/Flame/SM_TallowFlame and M_TallowFlame. 2. Add a SceneComponent anchor to the desired prop exactly at the physical wick. Local +Z is flame up, local +X is draft direction. Anchor follows prop movement; flame uses absolute unit scale to avoid inheriting imported candle scale.
3. Add UTallowFlameVisualComponent to the holder; set WickAnchor. Set CandleSource explicitly for different-owner candles; otherwise component discovers it on its own owner. Optional GutterSource reads legacy proximity amount; leave null if unavailable.

5. InitializeVisual runs at BeginPlay. For runtime bindings, set properties then call InitializeVisual and check true. Missing anchor/assets safely return false. No root-anchor fallback and no gameplay mutation.
6. For first-person use, persist bFirstPersonVisual (Python: first_person_visual) on the component before visual creation. The runtime mesh is transient; changing only its current primitive type does not survive recreation. Share the camera projection with hands and candle (current FOV 90, scale .6); cinematic setup is in refine_cinematic_staging.py.
7. Set explicit FlameMesh/FlameMaterial references in the integrating Blueprint to guarantee asset cooking. Default runtime paths are for development convenience and do NOT guarantee packaging inclusion. Configure cooked asset inclusion if using C++-only setup.

DEFORMATION CONTRACT
Source is a closed 746-vertex / 1488-triangle unit teardrop, pivot at wick (0,0,0), top Z=1. It has 32 vertical subdivisions and UV V stores normalized height. Material uses PreSkinnedPosition rather than UV to avoid OBJ V-flip import ambiguity.
WPO is non-rigid: x/y bend grows with t squared. At root t=0 and x=y=0, so offset is exactly zero. Z squash is measured from wick. The mesh component never rotates or translates to fake flutter.
Material parameters: HeightCm (already includes animated height ratio), WidthCm (already includes width ratio), BendX/BendY (tip displacement in local centimetres), Emission (default 4). Material transforms local offset to world space after deforming; component clamps height .1..20 cm and width .05..10 cm. Enlarged render bounds contain deformation. No shadows/collision/navigation/overlaps on visual.
Gameplay Lit reads draft/guttering and optional proximity. Cupped reduces wind deflection to 12 percent and steadies the silhouette. Out/unacquired/missing source hides immediately and resets exposure/ignition. Transition back to visible adds a short .25s ignition flare after the actual successful relight, not while a match is pending. Shape flutter has continuous deterministic timing; no gameplay timer changes.
Standalone mode reads only standalone properties. PhaseOffset differentiates multiple flames.
