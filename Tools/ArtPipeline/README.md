# Environment pilot production gate

This is a read-only manifest interface, not an automatic Blender exporter or proof that supplied metrics are true. Run `python3 Tools/ArtPipeline/check_manifest.py path/to/manifest.json`. Exit 0 means the supplied report and review evidence meet the pilot gate; exit 1 means blocked.

Keep the Tripo download immutable in a raw directory. Work in a separate production .blend: clean/retopologize geometry, assign seams and create a new **ProductionUV** map. Do not rename generated UVs and call them finished. Raw UVs may remain as RawGeneratedUV for bake transfer. Bake source appearance only after production unwrap; avoid baking lighting into colour.

Pilot: crooked wooden toy cabinet, maximum envelope 140 cm wide x 45 cm deep x 190 cm high; preserve proportions within it, base-centre pivot, applied scale, 1–8k triangle target, 8k normal maximum; 20k maximum only when focal_asset_approved is explicitly true. These are staging asset dimensions, not permission to change map clearances. Fit eventual placement without narrowing current route. Closed manifold wood parts; separate drawer pieces allowed. No collision or gameplay integration in this gate.

Manifest fields (schema_version 1): asset_id `crooked_toy_cabinet`; relative file paths raw_source, production_source, export_mesh; export_sha256 of final inspected export. mesh object: triangles, non_manifold_edges, degenerate_faces, loose_vertices, scale_applied, pivot `base_center`, dimensions_cm `[140,45,190]`. uv object: layer `ProductionUV`, authored_after_import, zero_area_faces, out_of_bounds_faces, overlap_fraction, coverage_fraction, padding_px_at_2048. review object: checker_front, checker_back, checker_closeup paths, checker_approved, reviewer. Counts/fractions must describe the evaluated export mesh, not only the editing cage.

UV measurement: sum island area in 0..1 after subtracting overlaps for coverage; overlap_fraction is doubly-covered area / occupied area. No intentional mirroring for this unique-texture pilot. Minimum 8 pixel padding at 2048 and 45% occupied space. Checker views must include drawer sides and underside, and a readable numbered checker; review equal tile scale, no flipped lettering, stretching or broken seams. The named reviewer (human or agent) must inspect the actual images before setting checker_approved; this is technical review, not user concept approval. Record measured values; never fill zeros for unmeasured topology or overlap.

The checker binds the export using SHA256 and rejects missing files/LFS pointers. It cannot inspect .blend geometry or establish UV provenance itself. Subsequent integration still requires Blender inspection, material review and Unreal scale/collision/navigation checks. Do not use a passing manifest as approval to overwrite shared assets.

## Optional Blender measurement

Run in a separate headless process on a production .blend using `blender --background --disable-autoexec asset.blend --python Tools/ArtPipeline/extract_blender_metrics.py -- --collection EXPORT --output metrics.json`. This reads the evaluated mesh collection and writes only the JSON report; it never saves the blend. Review collection membership first. Reported dimensions are world-space combined bounds in centimetres using scene unit scale. Overlap, occupied coverage and pixel padding remain unknown, so this report alone deliberately cannot pass the production gate. Supply independently measured values and checker review, not invented zeros. Metrics do not establish UV provenance or certify the exported FBX; reimport/check the final export and record its hash.
